## Safari permission

Tab Shelf uses Safari's browsing-history permission only to read and manage tabs already open in Safari. It reads the title, URL, and favicon supplied for those open tabs so it can display domain groups, identify repeated pages, and perform actions selected by the user.

Tab Shelf does not build or transmit a browsing-history database. Preferences and an optional user-selected background remain in Safari's local extension storage.
