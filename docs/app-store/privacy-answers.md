## Safari permission

Tab Shelf uses Safari's browsing-history permission only to read and manage tabs already open in Safari. It reads the title, URL, and favicon supplied for those open tabs so it can display domain cards in local categories, identify repeated pages, and perform actions selected by the user.

Tab Shelf does not build or transmit a browsing-history database. Appearance preferences, an optional user-selected background, custom category names, domain assignments, saved card and category order, and collapsed state remain in Safari's local extension storage. Tab organization is stored separately from appearance and is not included in theme exports.

Automatic category rules execute locally. Dragging, keyboard moves, custom categories, and layout reset add no permission, account, application-owned network request, analytics, or remote service.
