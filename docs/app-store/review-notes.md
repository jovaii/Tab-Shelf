# App Review Notes

1. In Safari, open Safari Settings → Extensions and enable Tab Shelf.
2. Open several disposable tabs across at least two domains, including the same page twice.
3. Open a new tab to display the Tab Shelf page.
4. Confirm automatic grouping places one card per domain into local categories and marks the repeated page.
5. Use a card's dedicated handle to reorder it inside a category, then drag it into another category. Reopen a Tab Shelf page and confirm both choices persist.
6. Use the card and category move menus to repeat the organization with the keyboard path.
7. Create a custom category named `Review`, move a disposable domain into it, rename it, collapse it, and reopen Tab Shelf to confirm persistence. Delete the custom category and confirm its domain returns to automatic classification without closing the tab.
8. Open Theme Studio from the settings control. Select each of the five themes, then try a solid color, a gradient, or a local test image as the background.
9. Choose **Reset tab layout** and confirm automatic categories return while the selected appearance remains unchanged.
10. Test close actions only on the disposable pages: activate one moved tab, close one tab, then close a domain group.

Use disposable pages for every close-action check.

The extension has no sign-in flow. Safari permission is used only to read and manage tabs already open in Safari. Organization affects only the Tab Shelf view and never changes Safari's native tab order, windows, or Tab Groups.
