# App Review Notes

1. In Safari, open Safari Settings → Extensions and enable Tab Shelf.
2. Open several disposable tabs across at least two domains, including the same page twice.
3. Open a new tab to display the Tab Shelf page.
4. Confirm grouping places the open pages into one card per domain and marks the repeated page.
5. Test close actions only on the disposable pages: close one tab, then close a domain group.
6. Open Theme Studio from the settings control. Select each of the five themes, then try a solid color, a gradient, or a local test image as the background.

Use disposable pages for every close-action check.

The extension has no sign-in flow. Safari permission is used only to read and manage tabs already open in Safari.
