# Human Approval Packages

Tab Shelf uses a three-surface approval package whenever a product or release document needs explicit human confirmation:

- a complete Markdown source of record;
- a responsive Web mind map; and
- a one-slide Web summary.

The Web views translate the source into plain product language. They do not replace the source, omit boundaries, or claim approval that has not occurred. Public review materials remain English-only; a local translated review copy may be generated for a specific reviewer.
