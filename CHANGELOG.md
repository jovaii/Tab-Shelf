# Changelog

All notable changes to Tab Shelf are recorded here.

## [1.0.0] - 2026-08-24

### Added

- Safari new-tab shelf with uniform domain cards, duplicate detection, activation, and scoped close actions.
- Toolbar badge and local popover for the current web-tab count.
- Quiet Neutral, Mist Teal, Ice Lavender, Neon Bloom, and Storm Horizon themes.
- Theme Studio controls for gradients, local images, blur, opacity, contrast, text appearance, and accent color.
- Validated local theme import, export, and reset.
- Original generated App and extension artwork at eight PNG sizes.
- Loopback-only preview server and native WebKit desktop and compact acceptance runs.
- Official macOS packaging and recoverable installation scripts for full Xcode environments.
- Deterministic App Store source/generated readiness checks and a local-only archive command that never uploads.
- English privacy, support, contribution, GitHub issue-form, and App Store review material.
- Original privacy-safe product, theme, native-host, and social-preview visuals.

### Privacy and quality

- No accounts, telemetry, analytics, application-owned network requests, or third-party runtime dependencies.
- Minimal Safari permissions: `tabs` and `storage`.
- Dependency-free automated tests for data boundaries, UI contracts, preferences, Safari APIs, packaging, and repository audits.
- System fonts, semantic color roles, visible keyboard focus, reduced-motion handling, and responsive layouts.
- Exact source and generated-project boundaries, plus fixed tool-path, archive-argument, and signing checks for the local App Store archive workflow.
